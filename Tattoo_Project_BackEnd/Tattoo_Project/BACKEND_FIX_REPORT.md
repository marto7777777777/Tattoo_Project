## Compatibility and deliberate limitations

- Existing `RequestStatus` numeric values `0..8` are unchanged; `Cancelled` is appended as `9`.
- Historical applied migrations were not edited.
- Legacy private media paths remain readable through the protected media route so old rows are not broken.
- New managed media is designed for an absolute durable `Storage:RootPath`. For multi-instance production, that path must genuinely be shared/persistent; otherwise implement an object-storage provider.
- The environment used for this edit has no .NET SDK/runtime and no Docker. Build/test/EF claims are therefore not fabricated. See `TEST_REPORT.md`.
